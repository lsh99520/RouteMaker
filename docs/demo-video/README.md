# RouteMaker 시연 영상

`RouteMaker_demo.mp4` — 1920×1080, 30fps, 70.5초, 배경음악 포함.

## 장면
| 시간 | 장면 |
|---|---|
| 0–6초 | 문제 제기: 공고마다 다른 마감, 따로 챙기는 시험 일정 |
| 6–12초 | 서비스 소개 + 일정 화면(계절 배너) |
| 12–24초 | 01 공고 요건 추출: 마감·필수·우대 요건과 원문 인용 |
| 24–36초 | 02 시험 회차 역산: TOEIC 제584회 결과 12/8 → 지원 마감 1/15, 대안 제586회, SQLD 확보 불가 |
| 36–52초 | 03 준비 일정·AI 의견: 지원서 작성(11/29~12/5)을 11/22~28로 끌어 옮김 → TOEIC 준비와 7일 겹침 → AI 제안 12/1~12/7 적용 후 겹침 0일(해외 연수 12/10~16과도 안 겹침) |
| 52–58초 | 04 요약: 다음 할 일(2주 안 고정 일정 우선 → TOEIC 추가 접수 마감 11/26), 진행 중 채용, 가장 가까운 마감 |
| 58–64초 | 05 정확도: 실제 공고 20건 3회 반복(`eval/report_run1~3.md`)과 새 공고 7건 3회 반복(`eval/holdout/report_run1~3.md`)의 최종 결과 |
| 64–70초 | 아웃트로 |

## 무엇이 실제이고 무엇이 재구성인지
- 브라우저 속 화면(`source/f_*.png`)은 `design/season-banners` 브랜치 서버를 띄워 시연 데이터로 찍은 실제 화면입니다.
- 요건 판정·시험 회차·D-day 숫자는 서버가 계산한 값 그대로입니다.
- 03 장면의 달력은 끄는 동작을 보여 주려고 화면과 같은 모양으로 HTML에 다시 그렸습니다. 지원서 작성의 원래 위치(11/29~12/5)는 장면용으로 정한 날짜입니다(서버 초안은 1/8~14).
- 03 장면의 AI 의견 문구는 **배포 서버의 실제 AI 응답**입니다(2026-11-21, `claude-haiku-5-5`). 시연 사용자로 같은 이동(11/29~12/5 → 11/22~28)을 하고 `/api/plan/feedback`을 3번 불러 3번 모두 같은 결과를 받았습니다.
  - 옮긴 직후: 전체 '조정 권장', 겹침 7일은 '분산 필요'(근거: 같은 공고·시험 직전), 준비 기간 8일은 '주의만 필요', 제안 '가상테크 지원서 작성 → 12/1~12/7'(엔진 확인: 부담 점수 7 → 0, 겹침 7 → 0, 개인 일정 겹침 0 → 0)
  - 제안 적용 후: 전체 '주의 필요'('몇 군데 지켜볼 곳이 있어요'), 준비 기간 8일 '주의만 필요', 새 제안 없음
- 배경음악은 `source/bgm.py`가 코드로 만든 곡입니다(녹음·외부 음원 없음).

## 다시 만들기
```bash
cd docs/demo-video/source
node render.js            # frames/에 2115장 렌더링 (Playwright 필요)
python3 bgm.py bgm.wav    # 배경음악 (numpy 필요)
ffmpeg -framerate 30 -i frames/f%05d.jpg -i bgm.wav -af volume=-3dB -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest ../RouteMaker_demo.mp4
```
문구·순서는 `video.html`에서 고칩니다. 각 요소의 `--d`가 등장 시각(초)입니다.

폰트 `PretendardVariable.woff2`는 Pretendard v1.3.9 공식 배포 파일을 고치지 않고 그대로 넣은 것입니다(SIL Open Font License 1.1). 라이선스 전문과 저작권 표시는 같은 폴더의 `OFL-Pretendard.txt`에 있습니다(출처: github.com/orioncactus/pretendard).
