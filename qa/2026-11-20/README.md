## 회차 예시와 일정 원본 차이

- 기본 10/20 시연에서 충돌 때문에 바뀌는 회차는 README와 기존 테스트대로 582→583이다. 이때 상세 화면의 584회는 583회 점수가 부족할 경우를 위한 재도전 대안이다. 584회 접수가 11/16에 끝나므로 583회 결과(11/24)를 기다리면 접수할 수 없다.
- 583→584 충돌도 화면에서 재현했다. 별도 10/31 시연에서 기본 연수에 11/15 하루짜리 ‘583회 시험일 일정’을 추가했다. 달력에 ‘제583회 시험일(2026-11-15)이 개인 일정(583회 시험일 일정)과 겹쳐 제외 → 제584회 선택’이 나타났다.
- SQLD 63회는 저장소 데이터에 발표일 12/4와 늦은 후보 12/8이 함께 있다. 엔진은 12/8을 사용한다. **엔진 단독 경계 검사**에서 시연일 10/1, 가상솔루션 마감 12/6 17시로 두면 원본은 불가였고, 메모리에서 12/8 후보만 제거하면 63회(11/14 시험)로 가능이었다. 기본 10/20은 이미 63회 접수가 끝나 이 차이로 회차가 살아나지 않는다.
- Notion 연결에서 두 작업 카드가 404를 반환했다. Notion의 583→584 예시와 공식 발표일 12/4는 요청문에 기재된 카드 내용에 근거했다. 담당자가 시험 일정 출처를 대조해 데이터와 경계 테스트 갱신 여부를 결정할 일이다.
